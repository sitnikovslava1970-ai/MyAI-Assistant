# CAD examples

The current API exposes these starter workflows:

- `POST /cad/sample-plate/step`, `/stl`, or `/dxf` — generic four-hole test plate.
- `POST /cad/fpv-frame/spec` — calculate classic-X FPV layout dimensions.
- `POST /cad/fpv-frame/dxf` — export preliminary frame layout DXF.
- `POST /cad/propeller/spec` — calculate two-blade propeller planform parameters.
- `POST /cad/propeller/dxf` — export preliminary propeller planform DXF.

Use `/docs` on the running API for editable request examples.
