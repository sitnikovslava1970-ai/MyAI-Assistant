## План проверки в Autodesk Inventor 2025
Inventor 2025 выбран как целевая среда для последующей инженерной проверки. Автоматически создать нативные `.iam/.ipt` файлы без установленного и запущенного Inventor нельзя; на текущем этапе CI формирует STEP/STL/DXF, а фактическая трансляция в Inventor ещё не выполнена.

### Сборка STEP
1. Скачать ZIP-артефакт run #165 и распаковать в отдельную папку проекта.
2. В Inventor выбрать File > Open, тип STEP, открыть `FPV_7in_ClassicX_Assembly.step`.
3. В Import Options сохранить структуру сборки, включить Save Components during Load и Check Parts during Load; единицы импорта — миллиметры.
4. Не выбирать Import Assembly as Single Part: для проверки нужна структура отдельных компонентов.
5. Сохранить созданные детали как IPT, верхнюю сборку как IAM; разместить все ссылки в общей структуре проекта.
6. Сохранить Translation Report и проверить отсутствие потерянных компонентов, пустых тел и ошибок трансляции.

### Плоские DXF-профили
1. Для каждого из девяти DXF создать отдельную IPT и активировать 2D Sketch.
2. Использовать Insert > ACAD, выбрать DXF и импортировать слои OUTLINE и HOLES; NOTES оставить справочным слоем.
3. Явно установить миллиметры и проверить масштаб 1:1 по контрольным габаритам.
4. Проверить замкнутость профиля, отсутствие дубликатов/самопересечений и корректное распознавание областей эскиза.
5. На копии профиля выполнить тестовую операцию Extrude для подтверждения пригодности контура к созданию тела; не использовать её как CNC-разрешение.

### Критерии приёмки Inventor
- Дерево сборки содержит ожидаемые отдельные компоненты.
- Все импортированные тела присутствуют и не пустые; отчёт трансляции сохранён.
- Контрольные габариты совпадают с манифестом и исходными параметрами в пределах точности обменного формата.
- Все 9 DXF открываются в миллиметрах и дают ожидаемые замкнутые профили.
- Проверены отверстия, слоты, вырез верхней пластины, взаимное положение деталей и отсутствие ошибок геометрии.
- Снимки экрана, измерения и Translation Report сохранены в `Reports/Inventor_2025/`.

**Статус Inventor:** целевая версия и методика зафиксированы; реальный импорт, сохранение IPT/IAM и измерения в установленном Autodesk Inventor 2025 пока не подтверждены. Это отдельный незакрытый пункт проверки.

## Ограничения выпуска
- В журнале DXF-экспорта run #164 есть повторяющееся предупреждение `exporting non-planar shape to 2D format`; необходимо подтвердить корректность плоской проекции в Inventor/CAM и, если требуется, исправить экспортёр.
- Не выбраны реальные аккумулятор и FC/ESC стек; не проверены их габариты, высота, разъёмы и центр тяжести.
- Не смоделированы держатель и трассы двух антенн O4 Pro. DJI требует не менее 50 мм от передающего модуля, камеры, металлических и карбоновых конструкций, рекомендует взаимный угол антенн 90° и выведение за контур рамы.
- Не утверждены длины M2/M3 винтов, шайбы, гайки, глубина резьбы и доступ инструмента.
- Не утверждены сорт и укладка карбона, материал опор камеры, компенсация фрезы/лазера.
- Не выполнены расчёт прочности, анализ вибраций/резонансов, тепловая проверка и лётные испытания.
