### Замечание по DXF-экспортёру

В журнале run #164 во время DXF-экспорта повторяется сообщение `WARNING, exporting non-planar shape to 2D format.` Экспорт завершился успешно, но предупреждение нельзя игнорировать только на основании успешного CI. Исходный код выбирает горизонтальную грань и передаёт её внешние/внутренние wire в `ExportDXF.add_shape`; необходимо отдельно проверить корректность плоской проекции и координат в целевой CAM-программе. До этого DXF остаются предварительными.
