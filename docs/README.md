
# MyAI-Assistant — Documentation

This directory contains project documentation.

## Planned Documentation

- `setup.md` — installation and initial setup.
- `architecture.md` — project architecture and modules.
- `security.md` — security rules and credential management.

## Development Rules

- Make changes in small, reviewable steps.
- Test each feature before marking it complete.
- Never store API keys, passwords, or access tokens in the repository.
- Document configuration and known limitations.
- Confirm important operations before executing them.

## Current Status

The project is in its initial documentation stage. No application modules have been implemented yet.
