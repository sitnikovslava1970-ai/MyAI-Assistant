
# Tests

This directory will contain automated tests for MyAI-Assistant.

## Planned Test Areas

- Core assistant logic.
- AI model integrations.
- Russian-Chinese translation.
- Document text extraction and validation.
- Excel and CSV processing.
- Error handling.
- Security-related behavior.
- Automation workflows.

## Testing Principles

- Test new functionality before marking it complete.
- Include normal cases and expected failure cases.
- Use sample data instead of sensitive business documents.
- Never include API keys, passwords, or access tokens in tests.
- Verify calculations with known expected results.
- Avoid making real external requests in routine automated tests.

## Current Status

Documentation only. Automated tests have not yet been implemented.
