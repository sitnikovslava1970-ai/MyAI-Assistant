
# Automation Module

This module will manage repeatable workflows for MyAI-Assistant.

## Planned Responsibilities

- Automate repetitive tasks.
- Coordinate document and spreadsheet workflows.
- Prepare data for user review.
- Support approved OneDrive and Power Automate workflows.
- Track task status and report errors.
- Provide clear results when a workflow completes.

## Safety Rules

- Ask for confirmation before deleting or overwriting important files.
- Do not send external messages without user approval.
- Validate input data before processing.
- Handle failures without silently losing data.
- Avoid repeating an operation when its previous result is uncertain.
- Keep logs free of passwords, API keys, and other secrets.

## Future Workflows

- Extract data from photos and prepare spreadsheet rows.
- Organize supplier documents.
- Validate purchasing and inventory information.
- Generate routine reports.
- Prepare Russian-Chinese supplier messages for review.

## Current Status

Documentation only. No automation workflows have been implemented yet.
